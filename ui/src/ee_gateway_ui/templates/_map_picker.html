{# EE Gateway UI shared map picker (0.6.5). GPL-3.0-only; see LICENSE at the repository root. Progressive enhancement over the coordinate fields: click the map or drag the pin and the fields fill in; edit the fields and the pin moves. The fields stay the source of truth and the server never sees any map state, so everything keeps working with JS off or tiles unreachable. Leaflet is vendored (no CDN); tiles load from openstreetmap.org in the OPERATOR'S browser only. The gateway containers make no new network calls. #}
Or pick on the map
Click to drop the pin, drag it to fine-tune, zoom in for rooftop accuracy. Map data © OpenStreetMap contributors.
